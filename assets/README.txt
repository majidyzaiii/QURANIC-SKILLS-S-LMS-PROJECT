QURANIC SKILLS LMS - LOGO ASSET FOLDER INSTRUCTIONS
============================================================

[URDU]
Aap apna logo is folder ("assets") mein add kar sakte hain:
1. Apne logo ki image file ko copy karein.
2. Is "assets" folder ke andar paste karein.
3. Us file ka naam "logo.png" ya "logo.svg" rakh dein.
4. Browser refresh karein, aapka logo top header navigation bar mein nazar aayega.

Agar aap transparent background wala PNG use karenge to design aur zyada professional lagega.

------------------------------------------------------------
[ENGLISH]
To add your custom Academy logo:
1. Copy your logo image file.
2. Paste it into this "assets" directory.
3. Rename your file to "logo.png" (or "logo.svg").
4. Refresh your LMS dashboard in the browser, and your custom logo will appear in the top-left header bar immediately.
